Pharm.D Results Portal — Demo Website (Fixed Version)

This is a demonstration/prank website, not an official college portal. The 503 status is simulated in the browser and is not a real server outage. No actual student results are published.

Files:
- index.html — page structure
- style.css — responsive styling
- script.js — 5-second loading animation and simulated error
- logo.jpg — supplied logo image

Keep all files together in the same folder. On GitHub, upload all files to the repository root (the same level as index.html). Do not upload only the ZIP.

To update your existing GitHub Pages site:
1. Extract this ZIP.
2. Open your repository and choose Add file > Upload files.
3. Upload index.html, style.css, script.js, logo.jpg and README.txt from the extracted folder.
4. Commit changes and wait for GitHub Pages to redeploy.
5. Refresh the site. If the old style remains cached, open the link in an incognito tab or clear the browser cache.

Keep the demo label visible and do not collect real student information.
